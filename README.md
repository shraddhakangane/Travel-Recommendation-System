# 🌍 Travel Recommendation System

A full-stack Travel Recommendation System built using modern web technologies.

## 🚀 Project Goal

This project recommends travel destinations based on user preferences such as:

- Budget
- Interests
- Preferred Season
- Travel Duration
- Location

It also provides personalized trip planning and recommendations.

---

## 🛠️ Tech Stack

### Backend

- FastAPI
- PostgreSQL
- SQLAlchemy
- Alembic
- JWT Authentication
- Pydantic

### Frontend

- React
- Vite
- Tailwind CSS
- Axios
- React Router
- Framer Motion

### Deployment

- Frontend: Vercel
- Backend: Render
- Database: Neon PostgreSQL
